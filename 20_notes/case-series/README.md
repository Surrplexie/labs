# Case Series Notes

Cross-sample synthesis notes grouped by theme, packaging type, delivery mechanism,
or behavioral family. Each note links to individual sample findings and summarizes
shared patterns, distinguishing characteristics, and analytical lessons learned.

## How to use

- When two or more samples share a meaningful structural or behavioral trait, create
  or update a case series note here.
- One sample is enough to start a note -- the note documents the pattern, not just
  the instance.
- Link back to individual sample files using relative paths:
  `../../03_findings/sample_01.md`

## Adding a new case series

1. Create a new `.md` file in this folder with a descriptive name (kebab-case).
2. Open with a one-paragraph summary of the theme.
3. Add a "Samples in this series" table with links.
4. Add "Common patterns", "Distinguishing features", and "Analytical notes" sections.
5. Update the table above.
